Install

One file and a few clicks. No administrator rights are needed: GoodLuck! is installed for you alone.

On Windows

  1. On the download page, press Download for Windows. You get GoodLuck-Setup-1.3.0.exe.
  2. Open it. If Windows shows Windows protected your PC, press More info, then Run anyway. Windows does not know GoodLuck! yet because it is not signed with a paid certificate, and it may ask again for a new version.
  3. Choose I accept the agreement and press Next. Keep the folder it suggests and press Next.
  4. Create a desktop shortcut is ticked: untick it if you do not want one. Press Next, then Install.
  5. Leave Launch GoodLuck! ticked and press Finish.
Done whenGoodLuck! opens on a screen called Setting up. From now on, open it from the Start menu: it is called GoodLuck.

On a Mac

  1. On the download page, press Download for Mac. You get GoodLuck-1.3.0.dmg, for a Mac with Apple silicon (M1 or later).
  2. Open it, and drag GoodLuck onto Applications.
  3. Open GoodLuck from Applications. The first time, macOS says it cannot check it, because GoodLuck! is not registered with Apple: close the message, and do not move it to the Bin.
  4. Open System Settings, Privacy & Security. Near the bottom it names GoodLuck: press Open Anyway, then Open. macOS may ask again for a new version.
Done whenGoodLuck! opens on a screen called Setting up. From now on, open it from Applications, Launchpad or Spotlight: it is called GoodLuck.

A new version later

On Windows, download the new installer and run it: it replaces the old program. On a Mac, quit GoodLuck!, drag the new one onto Applications and choose Replace. Everything you have done is kept: your data lives in its own folder, not in the program.

If it does not workWindows calls the file unsafe and offers no Run anyway, or a Mac offers no Open Anyway: the computer belongs to an organisation that blocks unknown programs. Install GoodLuck! on a computer of your own. More in When something is wrong.
